硬件连接与演示流程

接线前断电；PCB、蓝牙模块、光电模块与开发板共地。FPGA 输入为 3.3 V 逻辑。
以下 Y21 等均为 FPGA 封装管脚名，不是排针物理位置编号。

一、八路输入
PCB 的 J_FPGA 接 PMOD1，输出松开约 0 V、按下约 3.3 V，固件 ACTIVE_LOW=0。
K1/key_in[0]：Y21；K2/key_in[1]：Y22；K3/key_in[2]：AB21；K4/key_in[3]：AB22；
K5/key_in[4]：AA20；K6/key_in[5]：AA21；K7/key_in[6]：AA19；K8/key_in[7]：AB20。
SW1 在 PCB 上选择触摸或机械输入，输入通路统一为高电平有效。
鼠标微动开关节点虽为按下接地，经 PCB 反相器后的 FPGA 输入为按下高电平。
应依据 PCB 信号标识逐线对应，不能将上述逻辑顺序直接当作排针脚序。

二、外设
光电 OUT：E13；拨弦模式使用低到高的上升沿。
蓝牙 JDY-31 TXD → FPGA C19；JDY-31 RXD ← FPGA C18；128000 baud，8-N-1。
蓝牙模块按其铭牌供电，GPIO 使用 3.3 V 逻辑；模块与开发板共地。
C18/C19 复用期间，相关 J13 SDRAM0 插座不连接 SDRAM0 器件。
音频：I2S_BCLK Y17、I2S_LRCK AB17、I2S_DIN AA16、PA_EN AB16。
HDMI 输出为视频；音频从板载音频口接耳机或有源音箱。
完整管脚定义以 fpga/src/ble_music_keyboard.cst 为准。

三、指示与指引
PCB LED1～LED8 为机械按键状态指示灯，由按键回路直接控制。
曲谱指引使用 PMOD0 独立 LED 模块，led_out[0:7] 的逻辑顺序对应：
P19、R19、T21、U21、P16、R17、R18、T18；低电平点亮。

四、演示顺序
1. 安装 APK，下载 FPGA SRAM 配置，连接 HDMI 显示器及板载音频输出。
2. 逐个按 K1～K8，确认音阶与键位对应，并观察波形与频谱变化。
3. 切换 PCB 输入选择开关，分别演示触摸和机械按键演奏。
4. 在 Android 应用连接 JDY-31，切换音色、音区和九种模式，观察确认状态。
   默认模式下分别演示八音色的短按、长按、快速重按及多键和弦，比较包络变化。
   钟琴持续按住会衰减至静音；风琴保持幅度较高；小提琴起音较慢。
5. 选择拨弦模式，先按住选音键，再触发光电输入上升沿。
6. 选择简谱图片，逐行核对识别内容后上传；收到成功提示后开始指引。
7. 连接独立指引灯模块，按目标键推进；重复音符先松开再按下。
8. 启动录音回传，演奏后停止，保存或播放 WAV。
