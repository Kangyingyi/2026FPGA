一、作品概述
作品通过 FPGA 实现多音色音乐合成、九种演奏与音效模式、三音区切换，并结合
电容触摸/机械按键输入、光电拨弦触发、Android 蓝牙控制和 HDMI 声音可视化。
配套 PCB 通过反相和通道选择电路统一输入极性，使两类输入共用 FPGA 音源。

二、提交内容
fpga/          FPGA 工程、Verilog 源码、引脚/时序约束、HDMI IP 及仿真用例
android/       Android 应用完整源码、Gradle Wrapper 与单元测试

verification/  随代码基线保留的工具生成报告和测试结果

6. fpga/docs/BLE_PROTOCOL.md：蓝牙帧格式和命令表。

四、主要功能
• 八路输入与多声部音源；八种音色选择及自动匹配的 ADSR 包络。
• 九模式：默认、滑音连奏、滑音常开、颤音、延时、拨弦、回声、混响、合唱。
• 低、中、高三音区；固定音量；不依赖压力传感器。
• 光电拨弦：按住按键选择音高，再以 E13 输入上升沿触发。
• HDMI 波形与频谱显示，音频经开发板板载音频路径输出。
• Android 经典蓝牙 SPP 控制、简谱图片辅助识别、曲谱上传和 LED 指引。
• 8 kHz 单声道数字音频回传，应用端保存 WAV。

五、版本标识

应用安装包：release/keyboard_score_2.1_row_order.apk
应用版本：2.1-score-row-order（versionCode 12）

八种音色自动选择不同固定包络，逐音符独立执行；详细参数和公式见
docs/06_ADSR设计与计算说明.txt。滑音、颤音及光电拨弦保留各自的包络路径。
