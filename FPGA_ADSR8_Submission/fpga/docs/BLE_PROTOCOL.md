# JDY-31 / FPGA 通信协议（双输入音乐键盘）

本工程使用 **经典蓝牙 SPP**，不是 BLE GATT。JDY-31 与 FPGA 的 UART 均为 **128000 baud、8-N-1**；50 MHz 时钟下 FPGA 设 `UART_CLKS_PER_BIT=391`，实际约 127877 baud。手机端使用本包内的 Android App。

## 帧格式

`A5 TYPE LEN_LO LEN_H PAYLOAD CHECKSUM`

长度为小端序；`CHECKSUM` 是从 `TYPE` 到载荷最后一个字节的 8 位求和（不含 `A5`）。FPGA 接收的命令载荷上限为 32 字节。该版本的命令和 ACK **没有序号**，也**没有 0x7E 握手**；应使用随包配套 App。

## 手机发往 FPGA

| TYPE | 载荷 | 用途 |
|---|---|---|
| `10` | 1 字节，0–7 | 选择音色 |
| `11` | 1 字节，0–2 | 选择音区：0 低音区 C3～C4、1 中音区 C4～C5、2 高音区 C5～C6；上电默认中音区 |
| `12` | 1 字节，0–8 | 演奏模式：0 默认、1 滑音连奏、2 滑音常开、3 颤音、4 延时、5 拨弦、6 回声、7 混响、8 合唱 |
| `20` | 无 | 开始上传曲谱并清空旧曲谱 |
| `21` | 3 字节：音高 0–7，时值 uint16 小端 | 追加一条曲谱事件；时值单位 10 ms |
| `22` | 无 | 提交曲谱 |
| `23` | 无 | 开始 LED 指引；需要先提交曲谱 |
| `24` | 无 | 停止 LED 指引 |
| `30` | 无 | 开始录音回传 |
| `31` | 无 | 停止录音回传 |

例如选择默认模式：`A5 12 01 00 00 13`；回声、混响、合唱分别为 `A5 12 01 00 06 19`、`A5 12 01 00 07 1A`、`A5 12 01 00 08 1B`。模式 9 及以上会收到参数错误 ACK。

选择低、中、高音区的帧分别为 `A5 11 01 00 00 12`、`A5 11 01 00 01 13`、`A5 11 01 00 02 14`。音区作用于所有演奏模式的按键声音；曲谱音高 0～7 仍表示 K1～K8 的键位，不能在一条曲谱事件中独立指定音区。

## FPGA 发往手机

- `7F`：2 字节载荷 `命令类型, 状态`。状态 `00` 成功，`01` 参数或长度无效，`02` 未知命令。上例的成功 ACK 为 `A5 7F 02 00 12 00 93`。
- `41`：66 字节载荷 `序号低字节, 序号高字节, 64 个 PCM 样本`。样本是 **8 kHz、8 位有符号、单声道 PCM**。App 按帧序号检测丢帧，并转换为 16 位 WAV 供播放或保存。

本版 App 的曲谱上传会逐条等待 ACK；但 FPGA 端 ACK 没有命令序号，录音时若链路拥堵仍可能有丢帧或 ACK 超时。录音流和控制命令共享串口，运行时应依据应用确认状态操作。
