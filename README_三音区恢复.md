# 九模式 + 低中高三音区恢复版

这一版基于 `ble_effects_capkeys_2026-10-27`，恢复此前三音区功能，并保留九种演奏/音效模式、电容键高电平有效、JDY-31 128000 baud 8-N-1、LED 曲谱指引和录音回传。

App 的低、中、高音区按钮使用当前无序号协议发送 `0x11`，载荷分别为 0、1、2。FPGA 上电默认中音区，App 蓝牙连接后再次确认中音区；按钮收到成功 ACK 后变蓝。原 10 月 14 日版使用带序号的 `0x11` 和 `0x7E` 握手，不能与本版固件交叉使用。

| 音区 | 八键对应音高 |
|---|---|
| 低 | C3 D3 E3 F3 G3 A3 B3 C4 |
| 中 | C4 D4 E4 F4 G4 A4 B4 C5 |
| 高 | C5 D5 E5 F5 G5 A5 B5 C6 |

音区对默认、滑音、颤音、拨弦、延时、回声、混响、合唱均生效。曲谱上传的 `0:时值`～`7:时值` 仍表示 K1～K8 的**键位**，播放或 LED 指引时按当前全局音区解释。现有曲谱格式不含每个音符独立的音区字段，因此不能直接描述一首曲子中途跨音区的音符；识别五线谱图片若要自动处理跨音区，必须进一步扩展曲谱协议和 FPGA 存储结构。

源码位置：`fpga/src/`、`android/app/src/`；协议见 `fpga/docs/BLE_PROTOCOL.md`。`fpga/sim/run_all_tests.ps1` 包含 UART 音区切换、音区越界拒绝、各合成引擎步进测试。构建方式与前版相同：Gowin 打开 `fpga/ble_music_keyboard.gprj`，Android Studio 打开 `android/`。

本版须同时使用新 APK 和新 `.fs`。烧录到 FPGA SRAM 后如果断电，仍需重新下载。实体板音高及音效听感须再测试确认。

本机验证：13 项 FPGA 仿真通过，另通过工程清单检查；Android `assembleDebug` 成功；Gowin V1.9.12.04 布局布线后 50 MHz 约束下 Fmax 为 50.215 MHz，Setup/Hold 违例端点均为 0。时序余量较小，后续改动需重新检查。
