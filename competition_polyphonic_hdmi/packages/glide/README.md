# 滑音独立代码包

此包只包含 `pitch_glide` 模块及其独立测试，不依赖颤音、蓝牙、DDS 或 HDMI 代码。工程里的同名模块仍在 `src/pitch_glide.v`；两份文件内容相同。**在同一个 Gowin/ModelSim 项目里只添加其中一份**，避免重复定义模块。

## 文件与测试

- `src/pitch_glide.v`：可直接交给蓝牙/音频集成同学的 RTL。
- `sim/tb_pitch_glide.v`：独立行为测试。
- `run_test.ps1`：只编译本包两个 Verilog 文件并运行测试。

在 PowerShell 中进入解压后的本包目录，执行：

```powershell
.\run_test.ps1
```

若 ModelSim 不在脚本的默认安装位置，用 `-ModelSimBin '你的ModelSim\win32aloem目录'` 指定。脚本会在本包内生成 `simlib` 仿真工作库；出现 `GLIDE_PACKAGE_PASS` 表示测试通过。

## 实现与接口

`clk` 为系统时钟；`rst_n` 低有效复位；`sample_tick` 为单周期音频采样使能（当前工程约 48.828 kHz）。输入 `target_q15` 是有符号的目标频率偏移，0 保持原音高，约 +4015 升 200 音分、-3577 降 200 音分；模块将目标限制在 -4096～+4096。输出 `current_q15` 是平滑后的偏移。

`speed=0` 在下一个 `sample_tick` 立即到目标；`speed=1..6` 越大越慢，7～15 按 6 处理。每个采样比较 `target_q15` 和 `current_q15`，按差值的约 `1/2^(speed+7)` 移动，差值很小时保持最小 1 Q15 单位，直至准确达到目标。复位置零；目标改成 0 后会平滑回中。

模块本身只产生音高偏移，不能单独输出声音。接入 DDS 时，对各声部的基础相位步进值使用 `实际步进 = 基础步进 × (32768 + current_q15) / 32768`。这属于由目标控制的连续音高弯曲；**不是**自动识别前后触摸音符并在两个音符之间插值的 portamento。需要 C4→D4 等音符间过渡时，上层必须指定目标和结束时机。

独立测试检查正向平滑、反向、无 `sample_tick` 保持、立即到目标、限幅及回中。包不含蓝牙接收代码，也不占用 FPGA 管脚。
