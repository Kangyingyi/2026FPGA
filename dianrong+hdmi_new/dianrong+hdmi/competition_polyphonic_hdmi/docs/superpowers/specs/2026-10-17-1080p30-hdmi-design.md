# Tang Mega 60K HDMI 1080p30 独立工程设计

## 目的和边界

在不覆盖已通过 Gowin 编译的 `competition_polyphonic_hdmi` 720p60 工程及其 `.fs` 的前提下，在 `E:\FPGA\work\competition_polyphonic_hdmi_1080p30` 建立独立的 1920×1080@30 Hz HDMI 版本。此版本用于更清晰地展示 FPGA 内部真实音频采样、连续频谱、复音数和主峰频率；它不是提高音频采样率、频谱分辨率或证明该板卡的绝对最高 HDMI 模式。

## 架构和数据流

- 沿用同一 GW5AT-LV60PG484AC1/I0、Dock 板的 HDMI TMDS 引脚、I2S 音频和按键连接，不改动音频输出算法。
- 沿用 50 MHz 系统时钟、现有 PLL 的 74.25 MHz 像素时钟及其 5 倍 TMDS 串行时钟。1080p30 使用 2200×1125 总时序：1920×1080 有效像素、水平前肩 88/同步 44/后肩 148、垂直前肩 4/同步 5/后肩 36。`74.25 MHz / (2200×1125) = 30 Hz`。
- 视频时序生成器改为独立 `video_timing_1080p30`；音频域到像素域仍用现有同步/稳定总线机制。1280×720 模块和工程不修改。
- 新 UI 保留四格 `POLY`、`KEY`、`SAMPLE`、`PEAK`，保留 256 个真实 PCM 样本的波形和 DFT 第 0～125 bin 覆盖的 0～1000 Hz 连续频谱，以及八个音符卡片。重新按 1920×1080 坐标排布，让文字、图表和轴刻度在屏幕上更清晰；不得只把 720p 像素放大。
- 波形横轴显示固定的 256 点音频历史；相邻样本之间的屏幕线段只作视觉连接，不进入音频或 DFT 计算。频谱横轴始终对应频率，标出 0/250/500/750/1000 Hz；峰值仍来自逐帧 DFT 的最大非直流 bin，并明确为单个主峰而非全部复音。
- 视频帧内的顶部指标使用同一份稳定快照，避免同一帧前后呈现不同数字。不得把按键映射的名义频率当成频谱实测结果。

## 错误处理及兼容性

- 显示器若不接受 1080p30，独立工程仍保留已验证的 720p60 `.fs` 作为现场回退；不自动覆盖原烧录文件。
- 如果 1080p30 新工程在综合、布局布线或时序检查中失败，标记为实验版，不交付为可烧录定版。不能仅以生成 `.fs` 判定成功。
- 图表外观只显示有限采样/DFT 频点的真实测量结果；更高屏幕分辨率不增加音频观测数据的数量或频谱分辨率。

## 验证及交付标准

1. ModelSim 验证 2200×1125 时序、30 Hz 帧率计算、HS/VS/DE 边界和新 UI 的四格指标、波形/频谱地址映射与五个 Hz 刻度；原 720p 仿真回归继续通过。
2. Gowin 对独立工程完成综合、布局布线和 bitstream 生成；50 MHz 系统域与 74.25 MHz 像素域 Setup/Hold TNS 均为 0，并保存具体 Fmax 报告和 `.fs` SHA256。
3. 硬件显示测试需用户把新 `.fs` 烧入实际板卡并连接可接受 1080p30 的显示器；编译及仿真不能代替这一步。若显示器不兼容，回退 720p60。
4. 提供独立工程路径、烧录文件路径、回退路径和简短操作说明。任何 1080p30 成功声明必须分别注明仿真、布线和硬件三种验证状态。
